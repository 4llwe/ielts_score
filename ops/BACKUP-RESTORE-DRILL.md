# Backup and Restore Drill

- Tetapkan RPO/RTO dan retensi backup.
- Ambil backup database dan inventaris storage tanpa menyalin secret ke laporan.
- Pulihkan ke lingkungan terisolasi.
- Verifikasi jumlah akun, enrollment, payment, attempt, submission, certificate, ticket, serta integritas RLS.
- Uji rotasi key jika backup terpapar.
