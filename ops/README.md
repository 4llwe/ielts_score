# Commercial Launch Evidence Pack

Dokumen di folder ini adalah prosedur dan formulir operasional siap pakai. Setiap formulir harus diisi oleh pihak berwenang dan dilampiri bukti pada folder `evidence/` sebelum transaksi publik dibuka.

1. `LEGAL-REVIEW.md` — identitas usaha, kebijakan, pajak, dan persetujuan penasihat hukum.
2. `CONTENT-RIGHTS-REGISTER.csv` — register asal dan hak penggunaan setiap materi.
3. `ASSESSMENT-VALIDATION.md` — protokol pilot dan validasi psikometrik.
4. `EXAMINER-CALIBRATION.md` — prosedur kalibrasi dan reliabilitas penilai.
5. `PENETRATION-TEST-BRIEF.md` — ruang lingkup pengujian keamanan independen.
6. `PAYMENT-RECONCILIATION-SOP.md` — rekonsiliasi, refund, dan penanganan selisih.
7. `BACKUP-RESTORE-DRILL.md` — simulasi backup dan pemulihan.
8. `MANUAL-WCAG-AUDIT.md` — audit aksesibilitas manual.
9. `PILOT-GO-NO-GO.md` — penerimaan pilot dan keputusan peluncuran.

Jalankan `npm run check:evidence` untuk melihat bukti yang masih belum tersedia. Script ini sengaja gagal sampai bukti nyata diberikan; template kosong tidak dianggap sebagai persetujuan.
